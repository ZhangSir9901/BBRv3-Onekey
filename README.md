# ⚡ Debian / Ubuntu 一键安装 XanMod BBRv3 & AI 智能网络动态调优 (双轨极客版)

一款专为 **Debian 12/13** 以及 **Ubuntu 20.04/22.04/24.04/26.04 (LTS)** 深度定制的 BBRv3 一键安装与网络生命周期管理工具。

本脚本摒弃了传统的“静态写死参数”与“繁琐场景选择”，全面进化为**基于物理内存的 AI 自适应计算**与**基于链路 BDP 的极客精准计算**。无论您的 VPS 是用于大并发建站还是高吞吐代理翻墙，均能榨干最后一滴网络性能。

---

## 🌟 核心突破与亮点

*   **🧠 AI 动态缓冲计算 (告别 OOM)**：彻底告别静态写死的 TCP 窗口参数。自动读取服务器物理内存，以千分之十五的安全阈值动态推算 TCP Buffer 上限，既保证大带宽吞吐，又绝对防止小内存机器因海量并发而内存溢出（OOM）。
*   **⚙️ 真正的“六边形战士”底层架构**：不再让用户纠结“建站”还是“翻墙”。底层一次性拉满 **TCP Fast Open (秒开提速)**、**TIME_WAIT 极速回收 (防端口耗尽)**、**TCP Notsent Lowat (防缓冲膨胀)**。一套参数，全场景通杀。
*   **🥇 BBRv3 唯一真神搭档 (FQ 调度)**：摒弃已被淘汰的 `cake` 与 `fq_codel` 补丁思维，全局启用纯正的 `fq` 队列算法，完美接管 BBRv3 的 Pacing (平滑发包) 速率指令，彻底规避跨国链路的微突发丢包黑洞。
*   **🛡️ 内核级 PMTU 动态黑洞探测**：开启 Linux 底层 MTU 探测机制，自动适应各种中转机、加密隧道与老旧路由，不再因数据包过大被静默丢弃。
*   **🥷 4 重静默冗余防 WAF 拦截**：内置高拟真 Chrome UA 伪装、IPv4 强制降级与临时文件落地校验，静默绕过 Cloudflare 403 阻断，完美适配阿里云香港、AWS 等高危 IP 段。
*   **🔄 智能比对与热应用**：若系统已是最新版 XanMod 内核，自动跳过安装，直接热重载 `sysctl` 网络参数，**免重启，即改即生效**！
