# ⚡ Debian / Ubuntu 一键安装 XanMod BBRv3 & 全栈网络动态极致调优 (双轨极客版)

一款专为 **Debian 12/13** 以及 **Ubuntu 20.04/22.04/24.04/26.04 (LTS)** 深度定制的 BBRv3 一键安装与全栈网络性能生命周期管理工具。

本脚本彻底打破传统脚本“静态死参数”与“片面调优”的局限，全面进化为**硬件容量感知、链路 BDP 极客计算、UDP/QUIC 极限扩容、Xray 零拷贝加速与双栈 IP 守护**的一体化完整体系。

---

## 🌟 核心突破与全栈亮点

* 🧠 **AI 动态内存感知与 Swap 保命气囊**：自动读取物理内存按千分之十五安全推算 TCP 窗口（防 OOM）；检测到小内存主机（≤1.5GB）且无 Swap 时，**自动挂载 1GB 虚拟内存保命气囊**，并锁定 `swappiness=10` 确保物理内存绝对优先。
* 🚀 **全栈 UDP / QUIC 协议极限吞吐**：突破 Linux 默认 200KB 的 UDP 缓冲区瓶颈，将网卡与 UDP 接收/发送缓冲强力扩容至 **64MB**，为 **Hysteria 2、TUIC、WireGuard、游戏及 HTTP/3** 释放满血传输能力。
* ⚡ **Xray / 代理底层零拷贝与高并发扩容**：将 Linux 管道缓冲提升至 1MB，大幅榨干 Xray/Sing-box 的 `splice()` 零拷贝吞吐；扩充连接跟踪表（`conntrack` 100万）与出站端口池（6.4万），彻底根除晚高峰连接卡死与断流。
* 🥇 **BBRv3 + FQ 黄金搭档与防排队**：全局启用纯正 `fq` 队列调度配合 BBRv3 Pacing 平滑发包；注入 `tcp_notsent_lowat=16384` 从源头消除缓冲膨胀（Bufferbloat），搭配 `tcp_fastopen=3` 与 `slow_start_after_idle=0` 实现首包秒开、常态满速。
* ⚡ **`initcwnd 32` 起步满速与 systemd 守护**：将默认路由初始窗口扩容至 32，消除 TLS 证书与首屏握手的多次 RTT 往返等待；配套开机持久化服务，重启/重连永不失效。
* 📁 **解耦独立配置与出厂快照一键回滚**：所有参数写入独立的 `/etc/sysctl.d/99-bbr-tune.conf`；首次调优自动备份出厂参数快照，支持一键安全还原出厂网络配置。
* 🎛️ **四大官方分支自适应与版本锁定 (Pinning)**：
  - **满血硬件 (v2/v3)**：小白模式默认匹配官方最新的 **MAIN 主线稳定版 (当前 7.2.x)**；
  - **老旧 CPU (v1)**：自动锁定并仅限安装 **LTS (6.18.x 长期维护稳定版)**，绝不提供不兼容分支以防死机；
  - **极客自选子菜单 (选项 5)**：支持自由切换 `MAIN`、`LTS`、`EDGE`、`RT`，并支持指定特定版本（如 `7.2.15-xanmod1`）与 `apt-mark hold` 版本锁定。
* 🌐 **三维 IP 架构自适应与断网守护**：自动识别 **双栈网络、纯 IPv4、纯 IPv6** 拓扑；针对双栈开启内核级转发并注入 `accept_ra=2`，彻底修复 Linux 开启转发后 IPv6 路由丢失的陈年断网 Bug。
* ⛔ **封闭虚拟化与国内云大厂安全熔断**：全自动识别中国大陆 IP 及阿里/腾讯/华为的国内与海外全系实例，**自动触发安全拦截**，坚决防止因缺少 AVX2 指令集或网卡驱动不兼容导致服务器变砖（Kernel Panic）。
* 🔍 **清单级 360° 深度状态体检 (选项 9)**：全面罗列内核架构、TCP、UDP/QUIC、高并发状态机、IP 栈及虚拟内存调度全量参数，清晰透明评估当前生效状态。

## 📊 调优模式与菜单架构 (场景精细分流)

脚本具备**防呆智能默认逻辑**（未调优默认回车选 `1`；已调优默认回车选 `0` 安全退出）：

| 选项 | 模式名称 | 运行逻辑与适用场景 |
| :---: | :--- | :--- |
| **1** | **[小白/一键] 综合环境稳健全栈调优**<br>*(🏆 适合建站+代理)* | 动态 TCP 缓冲稳健截断 32MB、32MB UDP/QUIC、适度连接保活。满血硬件默认配 MAIN(7.2)，老旧硬件自动锁定 LTS(6.18)。<br>**适用：VPS 上同时跑着建站 (Nginx/MySQL/Docker) 与代理的多功能生产环境，均衡内存防 OOM。** |
| **2** | **[新机/开荒] 纯代理极致加速全栈调优**<br>*(🚀 适合翻墙专机)* | 暴力拉满 64MB UDP/QUIC 缓冲、1MB 管道零拷贝、极速状态机回收。<br>**适用：单一翻墙节点、中转机、专线、落地机，彻底释放 Hysteria 2 / TUIC / Xray 极限吞吐。** |
| **3** | **[高手/极客] 目标节点精准手工调优**<br>*(🔧 专线测速定制)* | 基于底层物理定律 `Bandwidth * Latency / 8` 计算理论极限 BDP 窗口。<br>**适用：中转机/机场主/专线互联，输入实测最高带宽与平均延迟，榨干单条线路极限。** |
| **4** | **🔄 一键检查与在线升级**<br>*(脚本 & XanMod 内核)* | 自动检测云端脚本更新并支持一键热重载；**严格依据已安装的本地同策略内核**比对官方源候选版本，提供同策略无损升级。 |
| **5** | **🛠️ 自定义选择内核分支与版本**<br>*(MAIN / LTS / EDGE / RT / 锁定)* | **硬件自适应子菜单**：主流硬件支持自由切换 4 大分支，并可指定精确历史版本号（如 `7.2.15`）执行 `apt-mark hold` 锁定版本。老旧硬件自动阻断不兼容分支。 |
| **8** | **⏪ 一键回滚还原到系统出厂网络配置**<br>*(Rollback to Factory)* | **出厂容灾恢复**：一键清除独立调优文件、注销 initcwnd 持久化服务并从出厂快照还原默认网络参数，安全零残留。 |
| **9** | **🔍 详细体检内核与网络加速状态**<br>*(Status Check)* | 全量清单级展示内核架构、已安装策略、initcwnd 32、TCP、UDP/QUIC、并发状态机、IP 栈及内存调度生效参数。 |
| **0** | **退出脚本** | 安全退出，无任何残留。 |

## 🛡️ 系统安全保障 (逃生舱设计 & 云厂商熔断)

1. **多内核逃生舱**：包管理器在安装新内核时会**默认保留系统原本的老内核**。万一遇到硬件不兼容导致开机异常，只需在商家 VNC/Console 重启并在 GRUB 菜单选择 `Advanced options` 即可一键选回老内核恢复。
2. **云厂商安全熔断**：为避免国内云厂商（阿里/腾讯/华为）裁剪指令集造成的引导崩溃，脚本会在执行前强制阻断此类机型，保护数据与连接安全。

## 📝 更新日志

### 📌 最新版本 (v2.4.0 - 2026-11-02)
* **吸收核心调优成果与高可靠独立配置架构 (方案 A)**：
  - **`initcwnd 32` 起步满速与持久化**：默认路由初始窗口扩容至 32，消除 TLS 握手及首屏首包等待，配套 systemd 开机持久化守护；
  - **解耦独立配置架构**：使用独立的 `/etc/sysctl.d/99-bbr-tune.conf`，与系统原生配置彻底解耦；
  - **出厂网络快照与一键回滚 (选项 8)**：首次调优自动备份原始配置快照，随时支持一键恢复出厂状态；
  - **APT 脏缓存自愈与 Hash Mismatch 自动修复引擎**：全面升级 `https://deb.xanmod.org` 加密源，并在安装异常时自动执行脏缓存深度清理与云端索引对齐重试，实现全自动静默自愈安装；
  - **补充高吞吐软中断参数**：注入 `netdev_budget=600` 与 `optmem_max=65536`，强化软中断与信令吞吐。

### 📌 历史版本 (v2.3.0 - 2026-11-02)
* **小白模式 CPU 硬件感知优选**：
  - 满血硬件（`x64v2`/`x64v3`）默认自动选用官方 `MAIN` 最新主线稳定版（当前 7.2.x），释放最新协议栈与 BBRv3 满血吞吐；

* **新增内核分支自选子菜单（选项 5 & 小白模式一键直达）**：

  - 支持指定自定义历史版本号（如 `7.2.15-xanmod1`），并支持 `apt-mark hold` 锁定版本，防系统更新被冲掉。
* **严格同策略升级机制（选项 4）**：
  - 无论本地安装了哪类分支，仅在本地同策略内核在官方源有更新时才提示升级，保证策略一致性。

  - 新增【一键检查与在线升级】（选项 4）：打通云端调优脚本热更新与官方 XanMod 内核版本智能比对升级。

* **修复 x64v1 指令集 404 报错**：识别到基础通用指令集时自动锁定官方专属 LTS x64v1 内核，杜绝安装时报包不存在的致命错误。
* **加固算术表达式注入防线**：极客模式输入参数引入纯数字正则过滤，彻底消除 Bash 算术扩展执行任意命令的安全风险。
* **磁盘 I/O 批量流水线优化**：将 `clean_sysctl` 重构为单次批量 `sed` 处理，大幅降低磁盘覆写次数与执行耗时。
